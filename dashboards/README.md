# Дашборды ReglerPro Controller

В каталоге четыре варианта панели. Все они используют одни и те же сущности
интеграции; отличается только оформление и сценарий использования.

| Файл | Стиль | Что нужно | Кому подойдёт |
|---|---|---|---|
| `kotel_dashboard.yaml` | `picture-elements` + штатные карточки | ничего | «живая» панель контроллера, кнопка F, максимум деталей |
| `kotel_dashboard_sections.yaml` | Sections (HA 2024.3+) | ничего | универсальный вариант: телефон, планшет, десктоп |
| `kotel_dashboard_mushroom.yaml` | Mushroom | HACS: Mushroom | компактный современный вид, быстрые действия |
| `kotel_dashboard_tablet.yaml` | Kiosk / настенный планшет | ничего (опционально kiosk-mode) | панель на стене, крупные элементы |

## Что выбрать

* **Обычный пользователь, телефон + планшет** — `kotel_dashboard_sections.yaml`.
  Это рекомендуемый вариант: адаптивная сетка, крупные `tile`, без HACS.
* **Любит Mushroom / уже установлен** — `kotel_dashboard_mushroom.yaml`.
  Карточки Mushroom дают «живой» вид и хорошо работают на телефоне.
* **Планшет на стене** — `kotel_dashboard_tablet.yaml`. Крупная панель,
  минимум текста, подтверждение старта/останова.
* **Нужна точная копия панели контроллера и кнопка F** —
  `kotel_dashboard.yaml` + `packages/kotel_display.yaml`.

## Установка

1. Скопируйте `dashboards/www/kotel/controller.png` в
   `/config/www/kotel/controller.png`. Если папки `www` не было, создайте её
   и перезапустите Home Assistant.
2. Для кнопки F (только `kotel_dashboard.yaml`) положите
   `dashboards/packages/kotel_display.yaml` в `/config/packages/` и добавьте:

   ```yaml
   homeassistant:
     packages: !include_dir_named packages
   ```

3. Перезапустите Home Assistant.
4. Создайте панель: **Настройки → Панели → Добавить панель → Новая панель
   с нуля**. В режиме правки откройте **Raw configuration editor** и
   вставьте содержимое выбранного YAML.
5. Замените префикс `kotel_kontroller` на свой. Посмотреть реальные ID:
   **Настройки → Устройства и службы → ReglerPro Controller → устройство →
   сущность → ⚙**. В редакторе работает Ctrl+H.

## Про ID сущностей

В примерах используется префикс `kotel_kontroller` — он получается, если
устройство называется «Kotel контроллер». У вас имя может быть другим,
поэтому ID вида `sensor.kotel_kontroller_temperatura_vody` нужно заменить
целиком, а не только окончание.

После перехода на `has_entity_name` **существующие `entity_id` не меняются**:
они хранятся в реестре. У новых установок ID формируются из имени устройства
и названия сущности, поэтому примеры могут совпадать не полностью.

## Состав панелей

### Sections

* **Обзор** — температура, состояние, связь, уставки, термостат, профили.
* **Климат** — термостат, датчик, расписание 7/7 (8 полей).
* **Диагностика** — аварии, версия прошивки, `params`, история.

### Mushroom

* чипы статуса (связь, состояние, шнек);
* большая температура воды;
* `mushroom-climate-card` с управлением;
* плитки уставок и комнатной температуры;
* большая кнопка старт/стоп с подтверждением;
* слайдеры настроек;
* график и профили;
* аварийная плашка.

Требуется HACS-расширение **Mushroom**. Если его нет, карточки
`custom:mushroom-*` покажут ошибку — используйте Sections-вариант.

### Tablet

* часы и дата;
* панель контроллера с крупной температурой;
* вторая температура (помещение);
* старт/стоп с подтверждением;
* индикаторы связи, розжига и климата;
* термостат;
* отдельный view «Настройки» с профилями и диагностикой.

Для киоска можно добавить HACS `kiosk-mode` (скрыть боковую панель) и
`browser_mod` (управление экраном), но панель работает и без них.

## Безопасность

* Не выводите на настенный планшет диагностику и профили, если к планшету
  есть доступ у гостей: там видно состояние контроллера и настройки.
* Старт/стоп в примерах использует `confirmation`, чтобы случайное нажатие
  не остановило котёл.
* Не публикуйте `/local/kotel_profiles/...`: файлы профилей доступны без
  авторизации (см. README).

## Проверка YAML

Перед вставкой можно проверить синтаксис:

```bash
python -c "import yaml, pathlib; [yaml.safe_load(p.read_text(encoding='utf-8')) for p in pathlib.Path('dashboards').glob('kotel_dashboard*.yaml')]; print('YAML OK')"
```

Если `yaml` не установлен: `pip install pyyaml`.
